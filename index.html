WilmaTools

AVOIMEN LÄHDEKOODIN SELAINTYÖKALUT

Selkeämpi näkymä Wilman tietoihin.

WilmaTools on valinnaisten Wilma-apuvälineiden kokoelma. Ensimmäinen työkalu kokoaa ryhmänohjaajan opiskelijoiden opintosuoritukset yhteen näkymään.

Asenna Tampermonkeyyn Lähdekoodi GitHubissa

Ominaisuudet

Opintosuoritusmatriisi

Värikoodatut arvosanat, rivittyvät opintojaksojen otsikot ja erilaiset kurssivalinnat samassa taulukossa.

Lukuvuosi ja huomiot

Automaattinen elokuu–heinäkuu-suodatus, mukautettu päivämääräväli ja huomiot arvosanoista 4, 5, 6, U ja K.

Paikallinen käsittely

Opiskelijatiedot käsitellään omassa selainistunnossasi. Suoritukset voi viedä CSV-tiedostoon.

Yhtenäinen työkalupalkki tietokoneelle

Asenna WilmaTools-työkalupalkki, niin opintoseuranta ja Chrome-tietokoneversion viestiluonnosten tallennus löytyvät Wilman yläreunan oikealla puolella olevasta yhteisestä valikosta. Suomi on oletuskieli. Jokainen työkalu asennetaan erikseen ja voidaan ottaa käyttöön tai poistaa käytöstä Tampermonkeyssa.

Asenna työkalupalkki (tietokone)

Asenna lisäksi haluamasi varsinaiset työkalut. Pelkkä työkalupalkki ei tallenna viestejä eikä kerää opintotietoja.

Viestiluonnosten automaattinen tallennus

Valitse laitteellesi sopiva erillinen versio. Firefox Android on kokeellinen ja toimii vain Android-puhelimen Firefox-selaimessa. Chrome Desktop on tarkoitettu tietokoneen Chrome-selaimeen.

Asenna erillinen käyttäjäskripti laitteesi selaimelle. Luonnokset (myös vastaanottajat) säilytetään paikallisesti selaimen localStorage-muistissa. Tarkista vastaanottajat aina ennen lähettämistä ja poista tallenne lähettämisen jälkeen.

Firefox Android — kokeellinen puhelinversio Ohjeet ja rajoitukset
Chrome Desktop — tietokoneversio

Asennus

  1. Asenna Tampermonkey.
  2. Avaa WilmaTools.user.js yllä olevasta linkistä ja asenna käyttäjäskripti.
  3. Avaa oman koulusi Wilman opiskelijan suoritussivu missä tahansa *.inschool.fi-osoitteessa ja valitse WilmaTools.

Tärkeää: Wilma voi ladata lisää kursseja Näytä kaikki -toiminnolla. Tämä versio lukee vain haetun HTML:n, joten tarkista tulosten kattavuus ennen käyttöä. Käytä vain opiskelijatietoja, joihin sinulla on oikeus.

OPEN-SOURCE BROWSER TOOLS

A clearer view of your Wilma data.

WilmaTools is a collection of optional browser utilities. Its first module brings homeroom students' course progress together into one overview.

Install with Tampermonkey Source on GitHub

Features

Course matrix

Colour-coded grades, wrapping course headings and different course selections in one overview.

School years and issues

Automatic August–July periods, custom date ranges and a separate issues view for grades 4, 5, 6, U and K.

Local processing

Student records remain in your authenticated browser session. Export selected course records as CSV.

Unified desktop toolbar

Install the WilmaTools toolbar for a shared menu near the top-right of Wilma. Finnish is the default, with English selectable. Course progress and Chrome desktop draft autosaving remain separate Tampermonkey scripts, each independently enabled or disabled in Tampermonkey.

Install desktop toolbar

Also install the tool modules you need. The toolbar alone does not collect grades or save drafts.

Message draft autosaver

Choose the version for your device. Firefox Android is experimental and intended only for Firefox on Android phones. Chrome Desktop is intended for Google Chrome on computers.

Install the separate userscript for your browser. Drafts, including recipient data, are saved in persistent local browser storage. Always verify recipients before sending and clear the saved draft after sending.

Firefox Android — experimental phone version Details and limitations
Chrome Desktop — computer version

Installation

  1. Install Tampermonkey.
  2. Open WilmaTools.user.js via the link above and install the userscript.
  3. Open a student gradebook on any school subdomain of *.inschool.fi and choose WilmaTools.

Important: Wilma may dynamically add more courses through Show all. This version reads fetched HTML only; verify completeness before relying on reports. Access only records you are authorized to view.
