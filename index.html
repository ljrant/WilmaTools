AVOIMEN LÄHDEKOODIN WILMA-TYÖKALUT

Opintoseuranta ja viestityökalut samassa kokonaisuudessa.

WilmaTools lisää tietokoneen Wilmaan yhtenäisen sivupaneelin, ryhmänohjaajan arviointinäkymän sekä viestipohjien ja luonnosten hallinnan. Jokainen käyttäjäskripti voidaan ottaa käyttöön erikseen Tampermonkeyssa.

Työkalut

Ryhmänohjaajan arviointinäkymä

Kerää opiskelijoiden suoritukset samaan matriisiin. Lukuvuosirajaukset, värikoodatut arvosanat, Huomiot-näkymä ja CSV-vienti.

Yhtenäinen käyttöliittymä eri Wilma-sivuilla. Ohjausryhmän pikalinkit, opiskelijalistan kopiointi ja ryhmien viestikuvakkeet.

Luo viestipohjia, valitse huomiota vaativia opiskelijoita ja hallitse viestiluonnosten paikallista tallennusta.

Viestit ja vastaanottajat

Huomiot-näkymässä voi valita useita opiskelijoita, ottaa käyttöön tallennetun viestipohjan ja avata Wilman viestin kirjoituksen. Vastaanottajia ei vielä esivalita eikä viestejä lähetetä automaattisesti. Ryhmän viestikuvake toimii vain, jos Wilman oma vastaanottajat esivalitseva linkki löytyy.

Asennus ja tietosuoja

  1. Asenna Tampermonkey.
  2. Asenna sivupaneeli ja haluamasi työkalumoduulit yllä olevista linkeistä.
  3. Kirjaudu Wilmaan ja avaa käyttämäsi työkalu. Tarkista tiedot ja vastaanottajat ennen käyttöä.

Arvosanat käsitellään paikallisesti selainistunnossa. Viestipohjat ja luonnokset voivat säilyä selaimen localStorage-muistissa ilman salausta. Wilma voi lisätä opintosuorituksia dynaamisesti ”Näytä kaikki” -toiminnolla, joten tarkista kerättyjen tietojen kattavuus. Käytä vain tietoja, joiden käsittelyyn sinulla on oikeus.

OPEN-SOURCE WILMA BROWSER TOOLS

Course progress and messaging tools in one place.

WilmaTools provides a unified desktop sidebar, homeroom course progress, message templates and locally saved drafts. Each userscript can be enabled separately in Tampermonkey.

Install sidebarGitHub source

Features

Homeroom course progress

Colour-coded course matrix, academic-year filters, issues view and CSV export.

Desktop sidebar

Consistent tools across Wilma pages, homeroom shortcuts, student-list copying and group-message icons.

Templates and drafts

Save message templates, select students with concerning grades and manage locally stored drafts.

Message recipients

The issues view supports selecting several students and a message template. Recipients are not automatically preselected and messages are never sent automatically. A group-message icon only works when Wilma exposes a suitable recipient-prefilled message link.

Privacy and installation

  1. Install Tampermonkey.
  2. Install the sidebar and whichever modules you need.
  3. Open Wilma and verify the information and recipients before taking action.

Grades are processed in your browser session. Drafts and templates can persist unencrypted in localStorage. Wilma may load additional course rows dynamically, so verify completeness. Only use student information you are authorized to access.
