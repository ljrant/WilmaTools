Firefox Android — kokeellinen puhelinversio

Kokeellinen versio. Tämä käyttäjäskripti on tarkoitettu vain Android-puhelimen Firefox-selaimeen, jossa on toimiva käyttäjäskriptien hallintalaajennus. Se ei ole tarkoitettu Androidin Chrome-selaimeen eikä tietokoneen Firefoxiin. Toimivuutta eri laitteilla ei ole vielä vahvistettu.

Työkalu pyrkii tallentamaan Wilman viestin aiheen, sisällön ja vastaanottajat selaimen paikalliseen muistiin. Luonnoksen voi palauttaa käsin.

Asenna Firefox Android -versio

Käyttö

  1. Avaa tämä sivu Android-puhelimesi Firefoxilla.
  2. Varmista, että selaimessa on käytössä käyttäjäskriptejä tukeva laajennus ja asenna skripti.
  3. Avaa oman koulusi Wilman viestin kirjoitussivu (*.inschool.fi/messages/compose).
  4. Testaa tallennusta ja palauttamista ensin vaarattomalla luonnoksella.

Tietosuoja ja rajoitukset

Viestiluonnokset ja vastaanottajat säilyvät salaamattomassa paikallisessa localStorage-muistissa myös selaimen sulkemisen jälkeen. Poista tallenne (Clear), kun et tarvitse sitä. Tarkista vastaanottajat aina ennen lähettämistä: palautus ei välttämättä synkronoi Wilman käyttöliittymän kaikkia tiloja. Työkalu ei poista tallennetta automaattisesti lähetettäessä.

WILMATOOLS · MESSAGE DRAFT AUTOSAVER

Firefox Android — experimental phone version

Experimental. This userscript is intended only for Firefox on an Android phone with a working userscript-manager extension. It is not designed for Chrome on Android or Firefox on desktop. Compatibility has not been confirmed across devices.

The tool attempts to save the Wilma message subject, body, and recipients locally and offers manual restoration.

Install Firefox Android version

How to use

  1. Open this page in Firefox on your Android phone.
  2. Ensure a userscript-manager extension is working and install the script.
  3. Open your school's Wilma compose page (*.inschool.fi/messages/compose).
  4. Test saving and restoring an unimportant draft first.

Privacy and limitations

Drafts and recipients persist in unencrypted browser localStorage after closing the browser. Use Clear when finished. Always verify recipients before sending: restoration may not fully synchronize Wilma's interface state. A sent message does not automatically clear the saved draft.
